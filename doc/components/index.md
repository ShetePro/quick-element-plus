# 组件列表

Quick Element Plus 提供以下业务组件，帮助开发者快速构建中后台应用。

## 数据展示

| 组件 | 说明 |
|------|------|
| [BasicTable 表格](/components/table) | 配置化表格，支持分页、字典数据、自定义列 |
| [BasicPagination 分页](/components/pagination) | 分页组件 |

## 表单组件

| 组件 | 说明 |
|------|------|
| [BasicForm 表单](/components/form) | 基础表单组件，支持配置化表单项 |
| [SearchForm 搜索表单](/components/form) | 搜索表单组件 |
| [BasicSelect 选择器](/components/select) | 选择器组件，支持字典数据 |
| [BasicRadio 单选](/components/radio) | 单选组件 |
| [BasicUpload 上传](/components/upload) | 文件上传组件 |

## 按钮组件

| 组件 | 说明 |
|------|------|
| [ExportButton 导出按钮](/components/button) | 数据导出按钮 |
| [ImportButton 导入按钮](/components/button) | 数据导入按钮 |
| [PermissionButton 权限按钮](/components/button) | 权限控制按钮 |

## 反馈组件

| 组件 | 说明 |
|------|------|
| [BasicDialog 对话框](/components/dialog) | 对话框组件，支持配置化内容 |

## Hooks

| Hook | 说明 |
|------|------|
| `useTable` | 表格数据管理：自动处理分页、加载状态、搜索 |
| `useDict` | 字典数据管理 |
| `useMessage` | Element Plus 消息提示封装 |
| `usePermissions` | 权限检查 |
